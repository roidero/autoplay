# What It DO??/?
This mod allows you to have a bot temporarily take control of a player tribe. Best used in Pass & Play, but works in other gamemodes too.

# Disclaimer
This mod technically works in Online Multiplayer, BUT if you set the bot difficulty to Hard or Crazy, ***any extra stars gained from the bot's Handicap bonus will be removed when attempting to spend them,*** followed by a "Failed to send command to server" error. Otherwise bots function fine.

For those who were intending to use the mod to get an unfair advantage online: Sorry, not sorry, cheaters!

# Keybinds
Note: *You may have to input an action before the bot starts playing.* (i.e. move a unit, build an improvement, research a tech, etc)

1: Easy Bot

2: Normal Bot

3: Hard Bot

4: Crazy Bot

X: Disable Bot
